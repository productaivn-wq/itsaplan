# PRODUCT.md — ACCORD Sovereign Agentic OS & Project Governance (`itsaplan`)

`[CANARY:AGENTS.md:GOVERNED]` · **Version**: 3.3.23 · **Status**: ACTIVE

## 1. Product Purpose

ACCORD (`itsaplan`) is a sovereign socio-technical project governance, 7-Horizon (`H1..H7`) portfolio execution, collaborative document/canvas, and autonomous AI agent orchestration platform. It unifies deterministic workflow accounting (`DET P=1`), human strategic judgment (`HUM`), and bounded AI agent execution (`AGT`) inside a single low-noise cockpit.

## 2. Platform & Form Factor

- **Primary Runtime**: Responsive web application (`Next.js` App Router + `Elysia` API + `PostgreSQL` revision bus) across desktop (`1280px–2560px`), tablet (`768px–1024px`), and mobile (`360px–540px`) viewports.
- **Interaction Paradigm**: Keyboard-first Linear / Vercel / Raycast cockpit (`Cmd+K` command layer, instant sidebar transitions `< 150ms`, and contextual `380px` slide-over governance drawers).

## 3. Users & Field Ergonomics

- **Portfolio Directors & Project Leads**: Govern `27+` portfolio projects, `H1..H7` WBS timelines, non-overlapping sprint cycles, and Soft/Hard WIP column guardrails in `<= 3` clicks without navigating deep settings mazes.
- **Engineers & Technical Writers**: Triage issues, log worklogs, co-edit Operational Transformation (`OT`) documents, inspect grounded citations, and reverse accidental destructive actions via `10s` Undo toast latches (`S7`).
- **AI Agent Operators**: Provision internal Mastra agents, external runner queues, schedules, and scoped MCP tool dispatches from a unified `AI Team` hub.

## 4. Surface Modes

- **`Operate` (Default)**: Kanban boards, Table views, `H1..H7` Gantt timelines, Cycles, Initiatives, AI Agent fleet, and `380px` `BoardCustomizeSheet` drawers — dense, calm, single-CTA chrome with zero decorative animations.
- **`Read`**: Collaborative Docs, Grounded Evidence Reader, and API documentation — comfortable line measure (`60–75ch`), clear typographic hierarchy, and distraction-free reading.
- **`Admin / Vault`**: Team governance, RBAC role matrices, Notification preferences, and hardware-bound Secret Vault — stacked borderless rows with explicit masked-secret reveal gates.

## 5. Accessibility & Inclusion

- **Contrast & Legibility**: WCAG 2.1 AA (`>= 4.5:1` primary text, `>= 3.0:1` secondary text) and APCA (`Lc >= 75` body) across both Light (`Swiss Vellum`) and Dark (`Milled Carbon`) themes, with a strict `>= 11px` font-size floor.
- **Bilingual Parity**: `100%` Unicode NFC Vietnamese (`vi`) and English (`en`) localization across all `33` translation namespaces, keyboard focus rings on every operable element, and `prefers-reduced-motion` compliance.

## 6. Constraints & Anti-References

- **Anti-Slop Blacklist**: Forbid gradient-clipped headings, multi-font display face sprawl (`Chakra Petch` + `IBM Plex Sans` + `IBM Plex Mono` only), sub-`11px` micro-text, card-in-card border nesting, shimmer skeleton bars on `Operate` surfaces, synchronous `window.prompt()` dialogs, and full-screen post-login changelog takeovers.
- **Route Governance**: Legacy `/god/*` and `/:team/:key/settings/*` stay permanently cut (`SPEC-283/284`); project configuration lives inline inside contextual `380px` slide-over drawers and 1-click empty-state actions.
